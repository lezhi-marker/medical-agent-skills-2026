# 差异基因筛选标准

## 主标准（固定）

显著差异基因须同时满足：

1. `padj < 0.05`（Benjamini-Hochberg 校正后的 q 值）；
2. `|log2FoldChange| >= 1`（即 Tumor/Normal 表达比 ≥ 2 或 ≤ 0.5）。

- 上调（Up）：`log2FoldChange >= 1` 且 `padj < 0.05`。
- 下调（Down）：`log2FoldChange <= -1` 且 `padj < 0.05`。
- 其余（包括 `padj` 为 `NA`）均记为不显著。

注意边界：`padj < 0.05` 为严格小于；`|log2FC| >= 1` 包含等于 1。

## 实现细节

- DESeq2：`padj` 来自 `results()` 的 BH 校正；独立过滤可能产生 `NA`，`NA` 不满足 `padj < 0.05`，不计入显著。
- limma：`padj` 来自 `topTable()` 的 `adj.P.Val`（BH）。
- 判定前先用 `is.finite(log2FoldChange) & !is.na(padj)` 过滤，避免 NA 参与逻辑运算。
- 火山图：横线 `y = -log10(0.05) ≈ 1.30`，竖线 `x = ±1`；颜色与上/下调定义一致。`padj = 0` 在绘图时以最小正浮点数代替，仅影响显示高度。

## 报告要求

- `summary.md` 必须写明：筛选标准、比较方向、显著上调/下调数、可检验基因数（padj 非 NA）。
- 不要在 `results.tsv` 中额外添加布尔列；显著性由上述两列按标准推导。
- 不要只按 p 值、只按 fold change，或对 `padj = NA` 手工赋值。

## 敏感性分析（可选，不替代主结果）

如用户要求，可在**单独目录**中复核更严/更松的阈值（例如 `padj < 0.01`、`|log2FC| >= 0.5`），并在报告中注明这些是敏感性分析，不能覆盖主标准输出。

## 解释注意

- 统计显著不等于生物学显著；样本量为 Normal 10 / Tumor 10，效应量与置信区间同样重要。
- 多重检验仅针对本次检验的基因集合；不同的预过滤会改变 `padj`。
- 阈值是分析约定，不是临床或机制结论。
