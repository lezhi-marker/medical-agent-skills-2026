# 医疗对话整理规则

本规则用于把 `dialogue.txt` 整理为 `qa_record.md`。核心原则：**只整理，不增补**。

## 1. 输入约定

- 文件编码 UTF-8（可带 BOM）；`#` 开头的行视为注释，空行忽略。
- 每行一条发言，格式为 `医生：内容` 或 `患者：内容`。
- 支持的说话人标签：`医生` / `医师` / `doctor`；`患者` / `病人` / `patient`。冒号可用中文或英文。
- 无说话人标签的续行，并入上一条发言。
- 连续同一说话人的多条发言会合并为一轮。

## 2. 问答配对

- 以**医生的一次发言**为一个提问（Q），其后、下一位医生发言之前的**患者发言**为回答（A）。
- 一次提问对应一个回答；连续的患者发言合并为同一个 A。
- 医生提问后没有患者回答：A 记为“（原文无患者回答）”，缺失项按清单全部标注“未提及”。
- 患者在对话开头先发言：Q 记为“（原文无对应提问）”，仍保留该回答并标注主题与缺失项。
- 不跨轮合并信息：每轮只使用本轮及之前的患者回答判断缺失，不把后文内容提前写入前轮。

## 3. 去口语填充（只删不改）

只删除以下**明确无实义**的成分：

- 句首语气词：嗯、啊、呃、额、哦、噢、唉、诶、哎（可连续出现）。
- 标点之间的同类语气词。
- 独立成句或后接标点的迟疑语：那个、就是说、怎么说呢。
- 句首“就是”且后面紧跟时间/状态词（最近、昨天、今天、前几天、上个月、去年、今年、从小、一直、平时、当时、那会儿）。

**保留不删**：然后、其实、我觉得、可能、大概、好像、就是（其他语境）、所有否定词、数字、单位、左右、偏、约、药名、部位、时间。它们承载原意或不确定性，不能当作填充词删掉。

删除后如整句为空，保留原文。

## 4. 保留原意

- 不概括、不改写、不调整语序、不合并不同轮次的事实。
- 保留否定（没有、不、否认）、可能性（可能、大概、好像）、程度词、具体数字与单位。
- 保留患者的原话措辞；只做规则允许的填充词删除与空白整理。
- 不对症状、诊断、用药做任何转述或解释。

## 5. 不补充资料外信息

- 不得加入对话中没有的症状、病史、检查、诊断、用药、剂量、时间、家族信息等。
- 不得根据常识推断病因、诊断或治疗建议。
- 不得引用外部指南、文献或药品说明。
- 主题标签与缺失项字段名只是**整理标签**，不是对患者的新增描述。
- 无法判断时，保留原文并标为“未提及”，不得猜填。

## 6. 主题判定

按提问中的关键词匹配，优先级从高到低：

1. 过敏史
2. 用药情况
3. 家族史
4. 既往史
5. 生活方式
6. 诊断与治疗
7. 检查与检验
8. 主诉与症状
9. 现病史
10. 其他

提问无匹配时再看回答；仍无匹配则为“其他”。主题仅用于检索，发现偏差时修正标签，**不得改动 Q/A 原文**。

## 7. 缺失项标注

每个主题有固定核查清单（见 `convert.py` 的 `TOPIC_FIELDS`）：

| 主题 | 核查字段 |
|---|---|
| 主诉与症状 | 起病时间、部位、性质、程度、诱因与缓解因素、伴随症状 |
| 现病史 | 起病时间、病程变化、诊疗经过、目前情况 |
| 既往史 | 慢性病史、手术史、住院史 |
| 用药情况 | 药名、剂量、频次、疗程、依从性 |
| 过敏史 | 过敏原、反应类型 |
| 家族史 | 家族成员、疾病名称 |
| 生活方式 | 吸烟、饮酒、饮食、运动、睡眠 |
| 检查与检验 | 检查项目、检查时间、结果 |
| 诊断与治疗 | 诊断、治疗方案、疗效 |
| 其他 | 无固定清单 |

判定规则：

- 只依据**患者回答**（累计到本轮），不依据医生的提问；医生问过但患者未答，仍算“未提及”。
- 字段关键词在累计回答中未出现，标注为 `<字段>（未提及）`；出现即视为已提及。
- 明确否认（如“没有，都不过敏”）视为已提及，不再标“未提及”。
- “未提及”只表示对话中没有出现该信息，**不代表临床上的阴性或不存在**。
- 关键词匹配是启发式规则，可能存在漏判/误判；必须人工复核，不能据此做临床推断。

## 8. 输出核验

1. Q/A 编号连续，数量与对话轮次一致。
2. 每条 Q/A 都能在原文中按“原文行”找到。
3. 删除的只有填充词；否定、数字、单位、药名、时间、部位均保留。
4. 记录中没有任何对话之外的医学事实、诊断或建议。
5. 缺失项只包含清单字段，格式统一为“（未提及）”；明确否认不被误标。
6. 全对话汇总表与各轮记录一致。

## 9. 禁止事项

- 禁止补写患者没说过的信息。
- 禁止把“未提及”解释为“没有”或“正常”。
- 禁止提供诊断、治疗、用药建议。
- 禁止改写原话以“更专业”或“更通顺”。
- 禁止把不同轮次的信息拼接成新的临床结论。
