# 医疗对话整理

## 适用任务

- 把逐轮医患对话转换为带 **Q/A 编号、主题、缺失项**的结构化 Markdown 记录。
- 删除口语填充词，保留原话意思与全部医学事实。
- 按固定清单标注对话中未出现的信息，统一写作“（未提及）”。
- **只整理，不诊断、不建议、不补充对话之外的医学知识。**

不适用：替代病历或诊断、补全缺失病史、多学科会诊记录、需要外部指南/文献支持的回答。

## 输入与输出

输入 `dialogue.txt`（UTF-8）：

| 要求 | 说明 |
|---|---|
| 说话人 | `医生：` / `患者：`（兼容 `医师`、`病人`、`doctor`、`patient`） |
| 格式 | 每行一条发言；无标签行并入上一条；`#` 开头为注释 |
| 内容 | 仅限对话原文，不要预先总结或补充 |

输出 `qa_record.md`：

| 部分 | 内容 |
|---|---|
| 概览表 | Q/A 编号、主题、截至本轮缺失项数 |
| 逐轮记录 | 主题、Q、A、缺失项（截至本轮）、原文行号 |
| 全对话汇总 | 各主题仍未提及的清单项 |

示例（已生成）：

- 输入：[examples/dialogue.txt](examples/dialogue.txt)（10 轮虚构对话）
- 输出：[examples/qa_record.md](examples/qa_record.md)

## 何时读取 references

- **运行或人工复核前**读 [references/organizing-rules.md](references/organizing-rules.md)：问答配对、填充词清单、原意保留、主题判定、缺失项规则。
- **修改 `convert.py` 的主题/清单/正则前**先读同一文档，避免把规则改成推断或补写。
- 用户对“未提及”含义有疑问时，引用其中的定义：只表示对话中没出现，不等于临床阴性。

## 如何调用

```bash
python .claude/skills/medical-dialog/scripts/convert.py \
  --input .claude/skills/medical-dialog/examples/dialogue.txt \
  --output .claude/skills/medical-dialog/examples/qa_record.md
```

- `--input` 默认 `dialogue.txt`，`--output` 默认 `qa_record.md`。
- Python 3.12，仅用标准库；输出文件固定 UTF-8。
- 脚本只做规则化整理：解析发言 → 合并同说话人 → 配对 Q/A → 删除填充词 → 判定主题 → 按患者回答核对清单 → 写 Markdown。
- 转换失败（找不到文件、无医生发言等）会以非零状态退出并打印 `[错误]`。

## 输出结构示例

```markdown
## Q1 / A1

- **主题**：主诉与症状
- **提问（Q1）**：您好，请说说这次主要是哪里不舒服？
- **回答（A1）**：最近两个月老是胃疼，吃完饭以后更明显。
- **缺失项（截至本轮）**：性质（未提及）；程度（未提及）；伴随症状（未提及）
- **原文行**：L3-L4
```

## 如何核验

1. **编号与轮次**：`## Q` 的数量等于对话轮次，编号连续；每轮一问一答。
2. **原文对照**：按“原文行”逐条比对；确认只删除了规则列出的填充词（嗯、啊、呃、额、哦等），否定词、数字、单位、药名、时间、部位、左右均保留。
3. **无新增信息**：逐句检查 Q/A，确认每个医学事实都能在 `dialogue.txt` 中找到；不得出现原文没有的症状、诊断、用药、剂量、检查结果或建议。
4. **缺失项**：只出现固定清单字段；“未提及”不被用于对话中已明确否认的内容（如“都不过敏”）。
5. **汇总一致**：全对话汇总表与各轮缺失项不矛盾；未涉及的主题不强行列出。
6. **可复现**：用同一输入重跑，输出一致（除生成时间外）。

快速检查命令：

```bash
grep -c '^## Q' .claude/skills/medical-dialog/examples/qa_record.md
grep -n '未提及' .claude/skills/medical-dialog/examples/qa_record.md
```

## 严禁事项

- 严禁添加对话中没有的医学信息，包括但不限于症状、病史、过敏、检查、诊断、用药、剂量、时间。
- 严禁根据常识或指南推断病因、诊断或治疗建议。
- 严禁把“未提及”解释为“没有”“正常”或“已排除”。
- 严禁为了通顺而改写患者原话；只允许删除规则内的填充词。
- 发现主题标签不合适时只改标签，不改 Q/A 原文。
